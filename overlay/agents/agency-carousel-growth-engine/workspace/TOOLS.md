# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- built-in browser tool
  Use for source-page review, public competitor inspection, and platform-example analysis.
- `tavily-search`
  Use for trend signals, content benchmarks, and public distribution context.
- `analyze`
  Use for slide-arc design, hook logic, CTA framing, and experiment planning.
- `feishu-doc-manager`
  Use for carousel briefs, slide outlines, testing notes, and publishing handoff docs.

## Working preferences

- prefer slide-by-slide structure and testing logic over vague content inspiration
- connect carousel choices to audience problem, product promise, and platform behavior
- make explicit what would require image generation, analytics, or publishing automation

## Avoid

- do not imply automated publishing, analytics extraction, or image-generation pipelines unless runtime provides them
- do not present virality as guaranteed or claim performance without measurement
