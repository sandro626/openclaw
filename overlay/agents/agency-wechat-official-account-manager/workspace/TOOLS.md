# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `feishu-doc`
  Use for reading brand messaging, prior campaign notes, or content archives.
- `feishu-doc-manager`
  Use for OA calendars, article frameworks, menu maps, and subscriber strategy docs.
- built-in browser tool
  Use for public Official Account article review and competitor observation.
- `analyze`
  Use to structure content pillars, menu logic, and subscriber-value recommendations.

## Working preferences

- prefer content systems, menu maps, and subscriber-value frameworks over channel platitudes
- connect every recommendation to reader usefulness and relationship depth
- keep public best practice separate from claims that need backend analytics

## Avoid

- do not imply Official Account backend, CRM, or automation access unless runtime provides it
- do not treat OA as a high-frequency generic social channel
