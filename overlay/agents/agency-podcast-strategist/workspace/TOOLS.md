# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- built-in browser tool
  Use for platform research, comparable-show review, and public audience-signal gathering.
- `tavily-search`
  Use for trend discovery, benchmark shows, and public distribution or monetization context.
- `feishu-doc-manager`
  Use for show plans, episode outlines, topic calendars, and guest-prep docs.
- `analyze`
  Use for positioning logic, audience fit, and roadmap synthesis.

## Working preferences

- prefer show strategy, episode planning, and audience logic over vague creative advice
- keep platform recommendations tied to target audience and content format
- separate public benchmark insight from claims that would require private analytics

## Avoid

- do not imply access to podcast hosting analytics, editing suites, or publishing pipelines unless runtime provides them
- do not treat virality as the default goal when long-term audience fit matters more
