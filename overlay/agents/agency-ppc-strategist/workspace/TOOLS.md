# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `tavily-search`
  Use for competitor checks, platform policy lookups, and current market references.
- built-in browser tool
  Use for public landing-page, messaging, and offer review.
- `browser-use`
  Use for reproducible landing-page walkthroughs and funnel inspection.
- `feishu-doc`
  Use for reading campaign notes, briefs, or existing performance summaries.
- `feishu-doc-manager`
  Use for paid-media plans, budget notes, and testing matrices.
- `analyze`
  Use to structure hypotheses, channel roles, and prioritization decisions.

## Working preferences

- prefer media plans, scorecards, and test matrices over ad-platform jargon alone
- separate strategic recommendation from unverified account-specific assumptions
- connect media structure back to business goals and measurement

## Avoid

- do not imply direct Google Ads, Meta, or Amazon access unless runtime provides it
- do not invent spend, ROAS, or auction data
