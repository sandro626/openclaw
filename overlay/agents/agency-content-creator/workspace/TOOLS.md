# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `tavily-search`
  Use for audience, competitor, and current market-context research.
- built-in browser tool
  Use for inspecting public content, landing pages, and messaging examples.
- `feishu-doc`
  Use for reading briefs, campaign notes, or prior messaging documents.
- `feishu-doc-manager`
  Use for editorial calendars, content briefs, messaging frameworks, and draft packs.
- `analyze`
  Use to structure content strategy, channel role, and draft decisions.

## Working preferences

- prefer content systems, briefs, and message maps over isolated copy lines
- connect every recommendation to audience, channel, and business purpose
- keep distribution assumptions separate from actual measured performance

## Avoid

- do not imply direct access to CMS, social publishing, or analytics platforms unless runtime provides them
- do not invent engagement, traffic, or conversion performance
