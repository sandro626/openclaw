# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- built-in browser tool
  Use for public editing references, platform examples, subtitle styles, and export guideline research.
- `tavily-search`
  Use for editing best practices, platform specs, and post-production technique references.
- `analyze`
  Use for pacing diagnosis, sequence review, and checklist-driven edit guidance.
- `feishu-doc-manager`
  Use for edit review notes, export guides, subtitle standards, and production checklists.

## Working preferences

- prefer clear edit notes and review criteria over software-specific fandom
- tie advice to retention, readability, and platform-safe output
- separate what can be judged from description or screenshots versus what needs direct timeline access

## Avoid

- do not imply direct control of CapCut, Premiere, DaVinci, Final Cut, or media storage unless runtime provides them
- do not recommend heavy effects or transitions when pacing and clarity are the real issue
