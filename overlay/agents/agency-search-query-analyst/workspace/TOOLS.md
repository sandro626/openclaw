# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `tavily-search`
  Use for current search-result patterns, competitor coverage, and demand-side research.
- built-in browser tool
  Use for inspecting existing SERP-like content and public landing pages.
- `feishu-doc-manager`
  Use for query-cluster summaries, opportunity maps, and recommendation notes.

## Working preferences

- prefer intent clusters and decision-oriented summaries over raw keyword dumps
- distinguish observed query evidence from content recommendations
- keep recommendations tied to the likely searcher job to be done

## Avoid

- do not assume paid keyword tools or private search-console access exist unless runtime explicitly provides them
- do not equate keyword presence with meaningful market demand
