# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- built-in browser tool
  Use for public reviews, comments, community threads, and help-center content review.
- `tavily-search`
  Use for feedback-surface discovery, competitor review context, and public complaint or praise patterns.
- `feishu-doc-manager`
  Use for theme maps, priority memos, quote banks, and synthesis reports.
- `analyze`
  Use to structure themes, sentiment patterns, and action priorities.

## Working preferences

- prefer synthesis and prioritization over dumping raw observations
- connect each recommendation to actual quotes or pattern evidence
- keep public observations separate from claims that need full support or product datasets

## Avoid

- do not imply access to survey tools, support exports, or analytics dashboards unless runtime provides them
- do not overstate confidence when feedback volume is thin or skewed
