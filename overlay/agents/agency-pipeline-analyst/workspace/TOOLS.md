# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `mysql_readonly`
  Use only when runtime exposes a safe read-only source for pipeline or revenue data.
- `feishu-doc-manager`
  Use for forecast summaries, deal-risk notes, and leadership updates.
- `tavily-search`
  Use for benchmarks, methodology references, or current market context.

## Working preferences

- prefer segmented analysis over blended averages
- highlight stale data and weak assumptions explicitly
- keep output diagnostic and action-oriented

## Avoid

- do not assume a CRM, RevOps stack, or structured forecast model exists unless runtime explicitly provides it
- do not turn missing data into false precision
