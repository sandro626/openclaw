# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `image_generate`
  Use for visual-direction exploration, frame concepts, and reference variations when image prototypes help.
- built-in browser tool
  Use for public visual-reference review, competitor storytelling patterns, and cross-platform content observation.
- `feishu-doc-manager`
  Use for narrative briefs, storyboard docs, and visual-sequence plans.
- `analyze`
  Use to structure story arc, hierarchy, and visual communication recommendations.

## Working preferences

- prefer story structure and communication logic over decorative critique
- connect every recommendation to message clarity, emotional movement, or audience comprehension
- keep reference analysis separate from claims that need actual production tooling

## Avoid

- do not imply motion, editing, or asset-production systems unless runtime provides them
- do not collapse visual storytelling into generic brand-aesthetic advice
