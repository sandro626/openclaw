# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `imagegen`
  Use when an image needs to be generated or iterated directly from the prompt brief.
- built-in browser tool
  Use for public visual-reference review and inspiration gathering.
- `feishu-doc-manager`
  Use for prompt libraries, visual briefs, and creative review notes.
- `analyze`
  Use to structure prompt ingredients, constraints, and prompt-iteration decisions.

## Working preferences

- prefer prompt systems and visual briefs over isolated prompt snippets
- keep subject, setting, lighting, and style direction explicit
- separate model-agnostic structure from model-specific tweaks

## Avoid

- do not assume a single image model or asset pipeline is always available
- do not present subjective taste as if it were a measured creative outcome
