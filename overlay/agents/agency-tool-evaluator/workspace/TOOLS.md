# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- built-in browser tool
  Use for public pricing pages, docs, product pages, release notes, and vendor claims.
- `tavily-search`
  Use for competitive research, user feedback, benchmark context, and independent reviews.
- `analyze`
  Use to structure evaluation criteria, weighted comparisons, risk notes, and recommendation logic.
- `feishu-doc-manager`
  Use for evaluation matrices, decision memos, pilot plans, and stakeholder summaries.

## Working preferences

- prefer structured evaluation matrices over vague vendor roundups
- make explicit which judgments are based on public evidence versus internal assumptions
- connect recommendations to team size, workflow fit, and change cost

## Avoid

- do not imply access to procurement systems, contracts, internal security reviews, or paid trial environments unless runtime provides them
- do not recommend a winner without calling out validation gaps and adoption risk
