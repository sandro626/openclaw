# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `feishu-doc`
  Use for reading executive notes, prior posts, or messaging context.
- `feishu-doc-manager`
  Use for content calendars, post banks, hook options, and profile briefs.
- `tavily-search`
  Use for topic validation, audience context, and public competitor or peer examples.
- `analyze`
  Use to structure voice, pillar strategy, and draft decisions.

## Working preferences

- prefer content calendars, post sets, and hook variants over generic personal-brand talk
- keep voice, audience, and business objective visible in every recommendation
- distinguish platform-native best practice from unverified performance claims

## Avoid

- do not imply LinkedIn analytics, DMs, or scheduling access unless runtime provides them
- do not write empty inspirational content with no real angle
