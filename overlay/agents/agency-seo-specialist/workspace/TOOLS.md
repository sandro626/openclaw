# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `tavily-search`
  Use for SERP research, competitor coverage, and search-intent context.
- built-in browser tool
  Use for public page inspection, site structure review, and content observation.
- `browser-use`
  Use when reproducible page walkthroughs or multi-page review is helpful.
- `feishu-doc-manager`
  Use for audits, content gap maps, and SEO planning notes.
- `analyze`
  Use to structure SEO findings, opportunity priorities, and risk notes.

## Working preferences

- prefer audit summaries, topic maps, and prioritized recommendations over generic SEO jargon
- separate public evidence from private-data assumptions
- tie SEO recommendations to user intent and content usefulness

## Avoid

- do not imply Search Console, Ahrefs, Semrush, or admin-level site access unless runtime provides them
- do not recommend manipulative or black-hat tactics
