# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `analyze`
  Use for workflow decomposition, bottleneck analysis, future-state design, and KPI framing.
- `feishu-doc-manager`
  Use for SOPs, workflow maps, operating checklists, and change summaries.
- built-in browser tool
  Use for reviewing public workflow references, tool docs, and example operating patterns.
- `tavily-search`
  Use for process-improvement methods, automation patterns, and benchmark context.
- `claude-code-task`
  Use when a workflow optimization depends on concrete automation design or code-aware execution planning.

## Working preferences

- prefer explicit handoff maps and responsibility boundaries over abstract efficiency advice
- tie automation ideas to specific repetitive tasks and exception paths
- keep measurable before/after criteria visible in every recommendation

## Avoid

- do not imply access to workflow engines, BPM suites, ticketing analytics, or enterprise event logs unless runtime provides them
- do not sell automation where policy, judgment, or edge-case handling still needs a human owner
