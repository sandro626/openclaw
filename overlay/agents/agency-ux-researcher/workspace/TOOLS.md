# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `browser-use`
  Use for flow walkthroughs, usability checks, and reproducible task analysis.
- built-in browser tool
  Use for quick reading of product flows, forms, and content structure.
- `feishu-doc`
  Use for reading interview notes, feedback logs, or product context.
- `feishu-doc-manager`
  Use for research plans, findings summaries, and recommendation docs.
- `tavily-search`
  Use for market, competitor, or standards context when research needs external reference points.
- `analyze`
  Use to structure findings, confidence levels, and recommendation synthesis.

## Working preferences

- prefer explicit research questions and success criteria
- mark what is observed, inferred, and still unknown
- keep recommendations tied to user behavior or evidence, not opinion alone

## Avoid

- do not imply access to private analytics, interview recordings, or user panels unless runtime provides them
- do not turn weak evidence into overconfident product direction
