# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `tavily-search`
  Use for competitor ad context, offer benchmarks, and current message references.
- built-in browser tool
  Use for landing-page inspection and offer-message consistency checks.
- `super_browser`
  Use when ad or landing review depends on repeatable page inspection.
- `feishu-doc-manager`
  Use for ad briefs, test matrices, and creative review summaries.

## Working preferences

- prefer hypothesis tables and test matrices over loose brainstorming
- compare ad message and landing experience together
- note platform-specific constraints when they matter

## Avoid

- do not assume ad account write access or platform analytics are available unless runtime explicitly provides them
- do not over-promise performance outcomes from copy alone
