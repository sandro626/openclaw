# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- built-in browser tool
  Use for public App Store and Play listing review plus competitor comparison.
- `browser-use`
  Use for repeatable listing walkthroughs across regions or competitors.
- `feishu-doc-manager`
  Use for ASO audits, metadata drafts, screenshot plans, and localization notes.
- `tavily-search`
  Use for category, competitor, and store-ecosystem context.
- `analyze`
  Use to structure conversion hypotheses, listing gaps, and prioritization.

## Working preferences

- prefer listing audits, metadata options, and asset plans over vague ASO advice
- separate discoverability, conversion, and localization concerns clearly
- keep public-store evidence separate from private console assumptions

## Avoid

- do not imply App Store Connect, Play Console, or attribution access unless runtime provides them
- do not claim download or conversion lifts without real measurement
