# TOOLS

Use existing OpenClaw capabilities as follows.

## Preferred capabilities

- `tavily-search`
  Use for current market signals, platform news, trend corroboration, and source gathering.
- built-in browser tool
  Use for quick inspection of public pages, landing flows, creator content pages, and channel examples.
- `super_browser`
  Use when a task needs deterministic page interaction, repeatable capture, or multi-step browsing.
- `feishu-doc-manager`
  Use to publish GTM plans, channel maps, and execution checklists into Feishu Docs.
- `dingtalk-feishu-cn`
  Use only when the runtime is explicitly set up to send China collaboration or bot messages.

## Working preferences

- Cross-check signals across more than one platform before escalating a recommendation.
- Separate public trend signals from inferred business actions.
- Keep channel strategies platform-specific instead of cloning one tactic everywhere.
- Make compliance, execution cost, and localization risk explicit.

## Avoid

- Do not assume access to platform admin APIs, ad accounts, or private data.
- Do not treat Douyin, Xiaohongshu, WeChat, Bilibili, and Zhihu as interchangeable.
- Do not use engineering or code-change tools unless the user clearly asks for implementation work.
