# Ops Workflows

此目录用于承接业务自动化、测试、办公与运维工作流技能的分组治理说明。

候选来源包括但不限于：

- `server-config/skills/automation-workflows`
- `server-config/skills/manage-platform-test`
- `server-config/skills/aliyun-oss-upload`
- `server-config/skills/ppt-creator`
- `server-config/skills/weather-cn`

当前加载约束：

- `skills.load.extraDirs` 只会扫描 `overlay/skills/*/SKILL.md` 这种一级目录
- 所以真正可加载的技能已落在：
  - `overlay/skills/automation-workflows/`
  - `overlay/skills/manage-platform-test/`
  - `overlay/skills/aliyun-oss-upload/`
  - `overlay/skills/ppt-creator/`
  - `overlay/skills/weather-cn/`

这里保留为治理入口和说明文档，不直接作为可加载 skill 目录。
